## Autonomous evidence layer

The candidate now turns each unresolved record into isolated researcher and adversarial-verifier jobs. Strict structured packets are ingested only after trusted code retrieves and hashes each cited source. Deterministic claim-type policy then corroborates, abstains or creates an exception; model output never directly edits prose. A nightly bounded workflow advances through the release queue only after the backend acknowledges both jobs. Missing credentials leave it in truthful software-only mode without advancing the cursor.

The public evidence lab exposes release-bound aggregate workload, claim policies and pre-registered prediction scores. Research packets, source snapshots, reports and exceptions stay private. The private editorial console shows only exceptions and records idempotent accept/reject/field-evidence/defer dispositions with a required reason. Forecast registration freezes the question, probability, cutoff, target, baseline and exact resolution source before outcomes are known.
